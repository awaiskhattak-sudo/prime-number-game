# Prime Number Game

## About the Project

Prime Number Game is a simple Python game based on prime numbers.

First, the user enters a number and the program checks whether it is Prime or Not Prime.

After that, the game starts with 5 rounds. In each round, the computer generates a random number and the user has to guess whether the number is Prime or Not Prime.

At the end, the program shows the user's score and a summary of all rounds.

## Features

- Check if a number is Prime or Not Prime
- 5-round guessing game
- Random numbers between 2 and 70
- User answers using P or N
- Score tracking
- Shows correct and wrong answers
- Displays a final round summary

## Technologies Used

- Python
- Random module
